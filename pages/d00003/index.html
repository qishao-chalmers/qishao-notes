# Dimension of each GEMV

Qwen 8B

Tensor Weight shape [out × in] Input x Output y
attn_q [4096 × 4096] hidden state [4096] Q [4096]
attn_k [1024 × 4096] hidden state [4096] K [1024]
attn_v [1024 × 4096] hidden state [4096] V [1024]
attn_output [4096 × 4096] concat attention heads [4096] hidden state [4096]
ffn_gate [12288 × 4096] post-attention hidden [4096] gate [12288]
ffn_up [12288 × 4096] post-attention hidden [4096] up [12288]
ffn_down [4096 × 12288] SwiGLU(gate, up) [12288] hidden state [4096]

Qwen 14B

Tensor Weight shape [out × in] Input x Output y
attn_q [5120 × 5120] hidden state [5120] Q [5120]
attn_k [1024 × 5120] hidden state [5120] K [1024]
attn_v [1024 × 5120] hidden state [5120] V [1024]
attn_output [5120 × 5120] concat attention heads [5120] hidden state [5120]
ffn_gate [17920 × 5120] post-attention hidden [5120] gate [17920]
ffn_up [17920 × 5120] post-attention hidden [5120] up [17920]
ffn_down [5120 × 17920] SwiGLU(gate, up) [17920] hidden state [5120]

Key differences vs 8B: hidden grows 4096→5120 (1.25×), FFN grows 12288→17920 (1.46×). n_kv_heads stays 8, so K/V output remains 1024 in both models (same KV head size, n_gqa goes from 4 to 5).
